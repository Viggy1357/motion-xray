## Changes and why

- Pydantic uses `allow_inf_nan=False`; tests no longer shadow the installed contracts
  package. Invalid scientific output is rejected: missing measurement reasons, invalid
  rep intervals, score/coverage bounds, invalid weights and valid joints without data.
  Measured zero remains distinct from missing. Off-image observations are preserved.
- Contract package and pose/report payloads moved to 0.2.0 together with fake provider,
  fixtures and generated schemas/types. Response models expose actual domain contracts
  in OpenAPI. API and model schema snapshots have drift checks.
- Module docstrings precede future imports, fixing baseline E402 findings rather than
  disabling lint rules. FakeLLMProvider uses the correct enum member. Optional Tavily SDK
  typing is isolated to its missing third-party module, not a blanket mypy suppression.
- Dedicated test Compose services have no runtime env file, state mounts or network at
  execution. CI calls the same entrypoints and regenerates contracts to detect drift.
- Third-party API/test/worker dependencies have hashed locks, frontend installs are
  frozen, build metadata is pinned, and Python/Node image digests are recorded in source.
  OpenAI 1.51.0 is paired with httpx 0.27.2 to fix the observed initialization failure.
- Next.js 14.2.15 was replaced by supported Maintenance LTS 15.5.28 with React 19.3.0.
  Selection was checked against the [14 Oct security advisory](https://nextjs.org/blog/nextjs-security-update-october-14-2026).
  Corepack/pnpm retain the existing pinned package-manager version.
- Setup/dev/test scripts perform their actions and propagate failures. Unimplemented
  analyze/evaluate/cleanup/seed commands exit 2. Docker build context excludes secrets,
  private footage, model/state directories and transient provider diagnostics.
- Web/API bind to localhost; web `/api` routes to internal API `/v1`. The partial Kiro
  evidence work was reviewed and adopted as unfinished work, not promoted to accepted
  T10 behavior. Live selection returns 503 before constructing a provider.

## Independent review and practical limits

A read-only subagent review found the initial test image omitted worker source and the
initial Node base was floating. Both were corrected. Its suggested ML import check
also passed. No further model review loop was needed.

The TestClient reports an upstream anyio alias deprecation warning. Tailwind warns that
the heading-only scaffold has no utility classes. These warnings remain visible.
The web is still a heading; most product routes return 501; worker execution is a stub.
Pose quality, tracking, synchronization, rep/metric accuracy, references, scoring and
structured coaching remain unvalidated. Debian OS dependencies still follow the pinned
base image's package repositories. Remote CI has not been run from this local task.

The two private `_nemotron*` helper scripts remain outside the checkpoint. Cached source
approval/filtering, safe domain classification, bounded Tavily calls and operator controls
remain T10. A successful import proves environment compatibility, not useful perception.
