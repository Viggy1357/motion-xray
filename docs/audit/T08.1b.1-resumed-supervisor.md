## Internal boundary

`services/api/app/supervisor.py::supervise_once` uses existing Store claims,
checkpoints, heartbeat and final publication fencing. Trusted synchronous callbacks
construct a child argument vector and validate output contents. Children run in a
new process group; inherited descendants are terminated on exit, and the direct
child is reaped. Each attempt owns an exclusive token directory. Failed or revoked
attempts are removed; collisions and newer attempts are preserved.

The parent accepts a regular, nonempty manifest up to1MiB with a simple basename
inside its own attempt. Root/controlled directories are private0700 and the manifest
0600. The child adapter must separately validate all referenced artifact content and
hashes. This is a private trusted worker boundary, not an OS sandbox. Callbacks must
be quick; their duration and SQLite lock latency are not preempted by the subprocess
deadline. A parent crash may leave files for future retention cleanup.
