# T05.2b posture observations audit

**Status:** engineering outcome / reference-pipeline validation only
**Authoritative:** false
**Date:** 22 October 2026
**Scope:** projected 2-D torso angle from MediaPipe pose landmarks; no clinical score, no approved tolerances, no public API or schema change.

## 1. What was implemented

- Pure Python torso-angle observation: hip→shoulder vector projected against a declared camera-up axis, signed degrees in `[-180, 180)`.
- Window statistics over fixed time intervals: min, max, excursion, start/end values, end change, with gap-invalid and boundary checks.
- Standalone offline hash-verified runner (`scripts/reference_posture_review.py`) driven by frozen diagnostic configs:
  - `data/review_configs/lat-posture-observation-v1.json`
  - `data/review_configs/lat-posture-roi-observation-v1.json`
- New frozen configs only; no new public schema, no threshold/scoring changes, no model training, no multiview, no new provider.
- Reused existing MediaPipe checkpoint and `movement.observations` angle arithmetic; original PTS preserved; no host installs.

## 6. Known pose failures

- Original Catalyst had inverted counts of 44/181 and 90/240 for shoulder-below-hip; after ROI crop these dropped to 3/181 and 0/240. Improvement is partial.
- QMotion bad-example original produced -106.06° at 21.63 s; the same PTS in the cropped
  diagnostic gave 33.88°. The original overlay visibly placed joints on the wrong body
  regions. A plausible cropped angle alone does not establish correct joint placement.
- IMSA right had a small invalid span that nullified excursion stats; per-camera pooling was not applied.

## 7. What these numbers do not mean

- Camera-up sign and image-right positive are conventions, not anatomical backward-gravity mapping.
- All-positive cross sign `+1` is an implementation convention, not a validated anatomical direction.
- Min/max values are descriptive statistics, not accepted score bounds.
- Window-end at 30 Hz PTS is a sampling boundary, not a rep boundary.
- No per-rep start/bottom/end labels exist; dynamic window excursion is not per-rep.
- Wrist proxy cannot satisfy the bar-endpoint core requirement.
- This run validates the reference pipeline, not six user reps or full-set detector improvement.
- Exact 10 reps is not a gate.
