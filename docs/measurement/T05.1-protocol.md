# T05.1 Protocol: Lat Pulldown Observable Metrics

Internal engineering contract for `movement.observations`. Not a public schema, biomechanics claim, or approved reference.

## 1. Interface

```python
angle_degrees(a: Sequence[float], b: Sequence[float], c: Sequence[float]) -> float
```

- Interior angle at vertex `b` for points `a-b-c`, in `[0.0, 180.0]`.
- Inputs must be finite, numeric, non-bool 2D or 3D coordinates. Mixed dimensionality or non-finite values raise `ValueError`.
- Zero-length segment raises `ValueError`.
- Implementation: `u = a - b`, `v = c - b`, normalize, clamp dot to `[-1, 1]`, `degrees(acos(...))`.

```python
@frozen
dataclass AngleObservation:
    frame_index: int
    timestamp_s: float
    side: Literal["left", "right"]
    metric: str
    space: Literal["projected_2d", "estimated_3d"]
    value: float | None
    reason: str | None
```

- `value` is `None` iff `reason` is non-`None`.
- Metrics produced by `measure_frame`: `elbow_angle`, `upper_arm_torso_angle`.

```python
measure_frame(frame: PoseFrame, *, side: Literal["left", "right"], width: int, height: int) -> tuple[AngleObservation, ...]
```

- Returns exactly four observations in fixed order:
  1. `elbow_angle` / `projected_2d`
  2. `elbow_angle` / `estimated_3d`
  3. `upper_arm_torso_angle` / `projected_2d`
  4. `upper_arm_torso_angle` / `estimated_3d`
- `elbow_angle`: interior angle at elbow for `shoulder → elbow → wrist`.
- `upper_arm_torso_angle`: interior angle at shoulder for `elbow → shoulder → hip` on the same side.
- **Projected 2D**: uses `xy` field, scaled by `width` and `height` (`x * width`, `y * height`).
- **Estimated 3D**: uses `xyz` field directly; model estimate only, no metric-scale claim.
- Gating precedence, per metric and per space:
  1. Missing joint → `missing_joint`
  2. `valid is False` → `invalid_joint`
  3. `interpolated is True` → `interpolated_joint`
  4. Required coordinate field is `None` → `missing_coordinates`
  5. Zero-length segment after scaling → `degenerate_geometry`
- Invalid `side`, non-positive dimensions, non-integer dimensions, or bool dimensions raise `ValueError` immediately.
- Pure function: no mutation, smoothing, gap filling, rep segmentation, confidence-derived claims, side auto-selection, or cross-arm averaging.

## 2. PoseFrame contract

Use `packages/contracts/contracts/pose.py`. `PoseFrame` exposes joints by predictable names (`left_shoulder`, `left_elbow`, `left_wrist`, `left_hip`, `right_shoulder`, etc.). Each `JointObservation` has `xy`, `xyz`, `valid`, `interpolated`.

## 3. What these angles are and are not

- **Elbow angle** is the geometric interior angle at the elbow. It is not "flexion" as `180 - angle`; any downstream flexion signal must explicitly transform and document the convention.
- **Upper-arm/torso angle** is the observable angle between upper-arm and torso segments. Candidate alias for `shoulder_drive`; does not measure lat activation, scapular depression, or shoulder adduction force.
- **Projected 2D** is camera-plane projection scaled to pixel coordinates. Not 3D truth.
- **Estimated 3D** is the model's estimate. Not validated true-3D measurement, world-vertical lean baseline, or approved reference.

## 4. Side, view, and baseline policy

- `side` is fixed anatomical `left` or `right`. The authorized diagonal-side clip usually shows the left side, but side is not assumed correct by `measure_frame`.
- Diagonal-side limitations: far-arm occlusion, foreshortening, no reliable world-vertical lean baseline from camera plane alone.
- **Upright/set baseline** for `torso_lean` requires explicit reviewer observations and a signed mapping convention (e.g., positive = backward lean). No arbitrary scoring tolerances here.

## 5. Segmentation and scoring boundaries

- Existing `low: 0.2 / high: 0.8 / dwell_s: 0.15` values are structure-only placeholders, not valid runtime bounds until calibrated in T05.2.
- Segmentation excursion calibration and approved-reference acquisition are separate gates.
- No invented numerical acceptance thresholds, approval flags, reviewer assignments, or label sets.

## 6. Reference acquisition and evidence routes

Candidate reference trajectories may come from:

1. Trainer-owned/permissioned capture.
2. Explicitly licensed clips with compatible variant/view/provider/mapping.

All reference artifacts must be immutable (recorded hashes), reviewed against documented criteria, and may be marked `experimental/blocked` pending validation. No fabricated reference media or licensing approval implied.

## 7. Manual labels and validation design

CSV label fields include:

- `original_source` — video/file identifier.
- `time_s` — source timestamp.
- `side` — anatomical side.
- `event` — `pull_start`, `turnaround`, `return_end`.
- `projected_angle_manual` — manual angle from original video.
- `annotation_uncertainty` — reviewer confidence or occlusion note.
- `reviewer_id` — labeler identity.
- `partial`, `occluded`, `reviewer_origin` — flags.

Distinguish independent human labels from automated candidates. Use a development/held-out split and require minimum failure-case coverage. Do not treat projected manual angles as 3D truth.

Use the blank headers in `templates/rep-labels.csv` and `templates/angle-labels.csv`.
They contain no labels yet. Rep times are original source PTS, including the10s
offset for this diagnostic. An incomplete endpoint stays blank with partial/notes.
Angle labels record independently placed pixel coordinates for the three named
landmarks, upright displayed dimensions and uncertainty; no model landmarks are
pre-filled. For elbow use shoulder/elbow/wrist; for upper-arm/torso use
elbow/shoulder/hip. Preserve author and label_origin (human vs automated); predictions
are never independent labels. Projected agreement checks localization and geometry,
not true3D validity. One reviewer can start the pilot; additional independent review
and a disagreement log strengthen the evidence.

## 8. Measured vs reviewed gates

Before a metric enters scoring it must pass:

- `measured` — produced by `movement.observations` from a valid frame.
- `reviewed` — independently labeled or authorized-reference reviewed.

A measured value without reviewed calibration is a candidate, not a scored output.
