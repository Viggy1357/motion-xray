## 1. Compatibility matrix (observed, not validated)

Matching view/provider/mapping/variant is **necessary but not sufficient** for
compatibility. Anatomical-side matching across views is **not** required: each
video may show a different visible side for a symmetric exercise; do not invent
a view/side match rule.

## 2. Hard prohibitions

- No pooled ranges across sources/views/variants.
- No projected-angle claim of physical lean (M1 needs calibrated baseline).
- No numeric score without reviewer-approved tolerances.
- No aggregate unless M1, M2, M3/M6 family, M4, M5 are all available **and** approved.
- No DTW claim of event-level comparison; DTW full-trajectory alignment is a separate task.
- Durations (M7) reported separately; never in the posture aggregate.

## 3. Source-observed ranges (unscored)

When compatibility is unknown, report per-source observed range deltas only:
`delta_low = x - source_low`, `delta_high = x - source_high`, flagged
`scored: false`, `compatibility: "unknown"`. These are descriptive, not norms.

## 4. Component score formula (conditional)

`s = 100 * max(0, 1 - distance_to_interval / tolerance)` applies **only if**:

1. tolerance is explicit, positive, and reviewer-approved; and
2. compatibility (view/provider/mapping/variant) is confirmed.

The denominator is **never** a default (no 180 fallback). If tolerance is
unreviewed: `score = null`, `reason = "tolerance_unreviewed"` (or
`compatibility_unconfirmed`).

## 5. Aggregate gate

Aggregate only when M1, M2, M3/M6 (one ROM family, not double-counted), M4, M5
are all available and approved. M5 requires validated bar/chest localization;
an unvalidated wrist proxy leaves the aggregate unavailable. Missing components
are preserved with reasons; a reason never permits aggregation.

## 6. Deterministic perturbation tests (required before approval)

- Perturbing a measurement away from the interval must never improve its score.
- Removing a required component must never improve or enable the aggregate.
- Missing input must yield `null` + reason, never a fabricated value.
