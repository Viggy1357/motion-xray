# T05.2c — provisional per-rep measurement proof

22 October2026. FR05/FR07/FR08/FR12. Implementation and diagnostic review, not an
approved technique score. Current evidence: `../audit/T05.2c-rep-review.md` and JSON.

## Labels and selection

`data/review_configs/lat-rep-labels-v1.json` freezes four QMotion corrected-section,
three Catalyst and three IMSA cycles, plus eight selected user cycles. Local
elbow-signal extrema proposed samples; Codex inspected start/bottom/end source frames,
rejected initial/final partials and top-position false cycles, and merged user
fragments where the images showed one movement. This is model-assisted visual
annotation, not independent human ground truth or qualified technique approval.

Source PTS are copied exactly from immutable artifacts. Reference0.25s/user0.5s
uncertainty fields are declared provisional timing allowances, not measured accuracy.
Bottom samples can lie within a hold; resulting phase durations are not validated
kinematic phase boundaries. Raw source/frame and annotation provenance remain explicit.

User chunks cover0–30s and25–55s; selected labels do not overlap or double-count their
shared footage. An ambiguous cross-chunk cycle is omitted. Exact recovery of the ten
reported repetitions remains secondary; selection follows visible cycle/coverage
criteria, not agreement with a reference or a desired score.

## Deterministic measurements

`movement.rep_observations.measure_rep` accepts an explicit `RepWindow` and the five
existing angle/space series. It returns32 components: two annotation-derived phase
durations, six projected torso components, and six components for each of elbow and
upper-arm/torso in projected2D and estimated3D. No automatic rep count or score.

- Events use the nearest raw sample within explicit max_gap_s; ties choose the earlier
  source PTS. An invalid nearest sample remains unavailable with its original reason.
- Complete-span min/max/excursion remain unavailable on missing data or excessive gaps,
  even where individually observed start/end values remain available.
- Torso pull change follows the shortest signed angular arc and requires observed
  pull-span coverage; ambiguous180-degree rotation is unavailable.
- Wrong sides, duplicate/out-of-order per-series PTS and malformed values are rejected.
- Camera-up projected torso angles are not gravity-calibrated backward lean. Estimated
  3D interior arm angles remain model estimates, not anatomical ground truth.

## Fixed crop experiment

`lat-rep-labels-user-roi-v1.json` adds a fixed user crop `[40,180,320,600]`, with hashes
and preserved original PTS. Labels were locked before this experiment. Original and
crop measurements stay separate; individual components are not cherry-picked between
representations. Cropping improved all-current-component availability from4/8 to7/8.
The remaining rep retains missing arm-range reasons. Eight physical reps are never
counted as sixteen just because both representations are present.

Thirty-two available components exclude unimplemented bar/chest localization. The
seven-rep measurement-coverage result does not make an overall technique score valid.
Source-specific observed ranges remain separate by metric, space, side and view;
their min/max are not population norms or accepted scoring tolerances.

## Reproduce and review

Inside the existing offline worker image, from `/workspace`:

```bash
PYTHONPATH=packages/movement:packages/providers:packages/contracts \
python scripts/rep_measurement_review.py \
  --annotations data/review_configs/lat-rep-labels-user-roi-v1.json \
  --output-dir artifacts/development/t052c-roi-measurements

python scripts/render_rep_review.py \
  --measurements artifacts/development/t052c-roi-measurements/measurements.json \
  --output-dir artifacts/development/reference-review \
  --report docs/audit/T05.2c-rep-review.md \
  --evidence docs/audit/T05.2c-rep-review.json
```

The pose artifacts and authorized footage are local prerequisites, not bundled assets.
Host wrapper `./scripts/test.sh python` passes625 tests with Ruff clean/mypy57 files;
26 focused library/CLI cases. Local page `http://localhost:8865/t052c.html` uses the
existing loopback-only review server; no cloud hosting or new recurring service.
Browser checks verified eight user rows, ten reference rows, seeking and source changes.
