## Multi-angle and reuse boundaries

Multiple reference views can help build a view-aware benchmark. Separate takes or
edited split-screen videos cannot automatically be fused into true3D. Triangulation
requires synchronized views of the same repetition plus camera calibration and
joint correspondence. Separate user sets may support complementary view-specific
assessments, with uncertainty, rather than a fabricated unified reconstruction.

Earlier screened Sports2D/Good-GYM methods and DTAIDistance address measurement,
segmentation and alignment components; they are not approved technique labels.
[Fit3D/AIFit](https://fit3d.imar.ro/) currently describes multi-view fitness sequences,
annotated repetitions and ground-truth3D skeletons. It is a relevant evaluation
candidate, not an installed lat-pulldown benchmark: exercise inventory, skeleton
mapping, access and intended-use terms must be checked before adoption. See the
existing reuse screen and integration review; no new dataset was downloaded.
