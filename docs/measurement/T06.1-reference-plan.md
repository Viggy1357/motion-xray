## 1. Goal

Move from raw measured angles to a calibrated, reviewed, authorized reference trajectory through narrow, independent steps. No scoring tolerance or approval invented before evidence exists.

## 2. Observable vs unobservable

| Type | Examples |
|------|----------|
| **Observable** | Elbow interior angle; upper-arm/torso angle; pixel-scaled 2D joint positions; timestamps. |
| **Unobservable** | Muscle activation; scapular depression; lumbar curvature; true 3D world position; injury risk; technique correctness. |

Coaching and scoring stay on the observable side unless an explicit, reviewed proxy is approved.

## 3. Phase roadmap

### Phase 0 — Raw angle proof
- Run `movement.observations.measure_frame` on the authorized diagonal-side clip.
- Output four observations per frame: `elbow_angle/projected_2d`, `elbow_angle/estimated_3d`, `upper_arm_torso_angle/projected_2d`, `upper_arm_torso_angle/estimated_3d`.
- Inspect time-series for plausibility, noise, missing-data patterns. No score.

### Phase 1 — Independent labels
- CSV fields: `source_sha`, `source_pts_start`, `source_pts_turnaround`, `source_pts_end`, `side`, `event`, `projected_angle_manual`, `uncertainty`, `partial`, `occluded`, `side_observed`, `reviewer_id`, `origin`.
- Two independent human labelers desirable if available; not newly mandatory. Minimum: one qualified reviewer plus a disagreement log pilot.
- Compare automated candidates to labels; do not treat projected manual angles as 3D truth.

### Phase 2 — Calibrated reps
- Use reviewed labels to calibrate segmentation excursion and duration/gap rules.
- Existing `low: 0.2 / high: 0.8 / dwell_s: 0.15` remains placeholder.
- Distinguish **segmented range** (detected motion excursion) from **good-technique range** (reviewer-approved). Reject normalizing tiny reps.
- Retain partial/uncertain cycles with reasons.

### Phase 3 — Authorized reviewed reference
- Acquire reference through approved routes:
  - Trainer-owned/permissioned capture with matching variant/view/provider/mapping.
  - Explicitly licensed clip with immutable artifact hash and documented provenance.
- Mark status `experimental`, `blocked`, or `approved` in a registry. No fabricated media.

### Phase 4 — Diagnostic comparison
- Align measured reps to approved reference using the T07 alignment contract.
- Report per-metric deviations and missing-data reasons, not a single score.

### Phase 5 — Held-out validation
- Reserve held-out clips/labels. Run pipeline blind.
- Measure failure-case coverage: occlusion, partial reps, side switches, interpolation.
- No labels supplied yet; held-out set not created.

### Phase 6 — Score later
- Only after Phases 0–5 produce stable evidence may scalar tolerances and a 0–100 score be defined.
- Any threshold requires version bump, regression fixtures, and reviewer sign-off.
